# Buildora — Student Technology Project Development Studio

> **"Your Idea. Our Build. Your Breakthrough."**

Buildora is a modern single-page website for a student-focused technology project development studio. Buildora helps college and university students turn technical ideas into full-stack web applications, AI/ML solutions, working prototypes, viva presentations, project reports, and complete documentation.

---

## 🚀 Key Features

1. **Brand Identity & Centralized Configuration**
   - Editable business configuration in [`src/config/site.ts`](file:///c:/Users/hymat/OneDrive/Desktop/buildora/src/config/site.ts).
   - Direct contact mailbox: `ananthujwal24@gmail.com`.
   - Custom geometric Buildora logo mark and wordmark.

2. **Hero Section**
   - Headline: *"From Project Ideas to Real-World Solutions."*
   - Interactive code editor mockup with tab switching (`model.py`, `App.tsx`, `report.md`).
   - Smooth navigation CTAs to explore projects or jump directly to inquiry.

3. **Services**
   - **Project Development**: Full-stack web apps, dashboards, REST APIs, databases, and mini/final-year prototypes.
   - **AI & Machine Learning**: Predictive modeling, classification/regression, NLP demos, and evaluation charts.
   - **Presentations & Reports**: PowerPoint decks, synopsis, technical reports, and viva demonstration guides.
   - **Documentation & Technical Support**: README files, setup guides, architecture diagrams, and API docs.

4. **Featured Projects Showcase**
   - 7 demonstration prototypes with honest status tags:
     - **ShopSphere** (MERN Stack · Prototype)
     - **EduPredict** (AI/ML · Prototype)
     - **QueryBot** (AI/ML · Concept)
     - **SpendWise** (MERN Stack · Concept)
     - **DocuFlow** (Web Development · Concept)
     - **SentimentIQ** (AI/ML · Prototype)
     - **CloudVault** (Decentralized Systems · Prototype)
   - Real-time category filtering (All, Web Development, MERN Stack, AI/ML, Decentralized Systems).
   - Accessible project detail modal with key features, architecture summaries, and a "Discuss Similar Project" CTA.

5. **Technology Stack Section**
   - Categorized cards for Frontend, Backend, Databases, AI & ML, Cloud/Decentralized, and Developer Tools.

6. **Process & Value Propositions**
   - 3-step workflow (Tell Us Your Idea → Plan the Approach → Build and Deliver).
   - 4 student-centric value differentiators (Requirement-Focused, Clear Documentation, Tech Flexibility, Presentation-Ready).

7. **Contact Form & Dispatch**
   - Client-side validation for Name, Email, Service dropdown, and Project Scope.
   - Mailto fallback automatically constructing an inquiry email to `ananthujwal24@gmail.com`.
   - One-click email copy button with visual feedback.

## 💻 Running Locally

### Prerequisites
- Node.js (v18+)
- npm (v9+)

### Installation & Development Server
```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev
```

Open `http://localhost:5173` in your browser.

### Production Build
```bash
# Compile TypeScript and bundle assets
npm run build

# Preview production build
npm run preview
```
